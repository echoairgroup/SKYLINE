How the radar area works

The public ADSB.lol point-query API returns aircraft within a radius of up to 250 nautical miles around one latitude/longitude point. SKYLINE places that coverage circle on the map. Drag the map to a different location to request aircraft around the new centre.

The current radar area is not global coverage in one request. The map can be moved anywhere, but only aircraft inside the selected radius are returned at a time. This avoids pretending that a regional receiver feed is a complete worldwide census.

What the aircraft data means

  • Callsign: aircraft-transmitted flight identification. It may be blank or stale.
  • Registration and type: supplemental aircraft metadata when available from the provider.
  • Altitude, speed and heading: transponder/receiver measurements. They may be absent or have different reference types.
  • Squawk and emergency: transponder code and reported ADS-B emergency indicator. A listed code is an indication, not confirmation of an incident.
  • Position age: the provider-reported age of the last position message. The website refreshes periodically; it is not a certified live surveillance display.

Data sources and licensing

Aircraft data: ADSB.lol public API. The API and public data are published under the Open Data Commons Open Database License (ODbL 1.0). The provider documents dynamic rate limits and asks production-use applications to contact them before relying on the service.

Map: © OpenStreetMap contributors. Map tiles are served by OpenStreetMap's standard tile service and remain subject to its tile usage policy.

Display library: Leaflet, with marker clustering for dense areas.

Coverage, privacy and limitations

  • Coverage depends on independent ADS-B/Mode-S receivers and the aircraft's equipment, altitude, terrain and radio propagation. Not every aircraft is visible.
  • Aircraft that do not broadcast a usable position, use privacy measures, or fall outside receiver coverage may not appear.
  • ADSB.lol may change availability, API policy or rate limits. A request can fail or return partial data.
  • SKYLINE currently queries a single 250 NM area at a time. Its periodic refresh is best-effort and automatically slows when the service reports rate limits.
  • This is an enthusiast information tool, not certified air traffic control, navigation, dispatch or flight-safety equipment.
  • The map service may receive ordinary request metadata such as IP address and browser headers. SKYLINE itself does not create an account or send location data to a backend.
