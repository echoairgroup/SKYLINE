What can I search?

  • Callsign: the flight identification transmitted by the aircraft, when available.
  • Registration: the aircraft's registration, when the receiver network has a match.
  • ICAO24: the aircraft's 24-bit transponder address, written as six hexadecimal characters.

A search only returns current data available to the provider. An aircraft may be missing because it is outside receiver coverage, not transmitting a position, using a privacy address or no longer airborne.
